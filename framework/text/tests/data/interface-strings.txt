# The interface strings of kosmo, grouped by the bundled font that shows
# them. The test `tests/coverage.rs` of `kosmo-text` fails when the
# character map of a font lacks a character of a string of its group, and
# lists every such character.
#
# A line that is empty or starts with `#` is a comment. `[<file>]` starts
# the group of the font whose file in the asset manifest is `<file>`; each
# font has one group. `<name> = <text>` is a string of the group above it,
# with a name of lowercase ASCII letters, digits and `-` that no other
# string of the group has. The text is everything after ` = `: `\\` is a
# backslash, `\u{<hex>}` the character with that code point in
# hexadecimal, and any other character stands for itself. A space at either
# end of a text, any other whitespace and control characters are written
# as escapes, and so are characters that cannot be seen, such as the soft
# hyphen U+00AD.
